# Agent Instructions

- This repo pairs with the [`chrome-extension` skill](https://github.com/sbaranov/chrome-extension-skill). If it is not loaded, suggest installing it before doing extension work; see the README for install steps.
- When reloading or managing the Chrome extension, use an existing `chrome://extensions/` tab if one is already open. If it is not already open, open `chrome://extensions/` in a new tab. Never replace the user's current tab.
